# 尖塔扫雷

[<kbd>中文</kbd>](./README.md) [<kbd>English</kbd>](./README_EN.md)

带有成长、商店、道具配置与风险收益机制的网页版扫雷小游戏。玩家在不同规模的矿区中排雷，赚取金币和经验，逐步打造自己的出战配置，并挑战更高难度的赏金局。

## 本次更新

本次版本围绕“精英格风险玩法”做了 3 个提升：

1. 新增精英格系统：每局会生成可识别的 `Vault`、`Scout`、`Doom` 三种精英格，带来不同的风险和收益。
2. 新增局内精英信息反馈：棋盘上方会显示剩余精英格、当前赏金倍率、已触发 Doom 次数，闭合精英格也有明显标记。
3. 新增强化结算与记录：结算面板会显示本局精英赏金结果，并按难度记录最高金币与最快通关时间。

## 游戏特色

- 经典扫雷操作：左键翻开格子，右键插旗。
- 四档难度：简单、进阶、困难、终极，拥有不同棋盘规模、地雷数量、目标时间和奖励权重。
- 成长系统：胜利获得金币和经验，升级后提高收益倍率。
- 商店系统：可购买永久道具，并在出战配置中自由搭配。
- 成就与每日任务：提供中长期目标与稳定金币来源。
- 精英格风险收益：赌对了会放大奖励，赌错了可能让棋盘更危险。
- 本地存档：等级、金币、道具、最佳记录等会保存在浏览器 `localStorage`。

## 精英格说明

每局会根据难度生成固定数量的精英格：

- `easy`：1 个
- `normal`：2 个
- `hard`：3 个
- `ultimate`：4 个

精英格类型：

- `Vault`
  - 触发后本局金币赏金 `x1.12`
  - 可多次叠加
- `Scout`
  - 自动展开周围最多 3 个安全未开格
  - 若周围没有合适目标，则改为揭示 1 个全局安全格
- `Doom`
  - 触发后本局金币赏金 `x1.20`
  - 同时会向棋盘中补入 1 颗新的隐藏地雷
  - 若没有合法位置补雷，则只保留赏金增益

## 如何运行

这是一个纯前端项目，不需要构建步骤。

1. 进入项目目录。
2. 用浏览器打开 `index.html`。
3. 开始游戏。

也可以使用任意静态文件服务器，例如 VS Code Live Server。

## 玩法说明

- 左键：翻开格子。
- 右键：插旗或取消插旗。
- 新一局：按当前难度重新开始。
- 升级：消耗金币提升角色等级。
- 购买道具：永久解锁新能力。
- 出战配置：控制本局生效的主动与被动道具。
- 重置存档：清空当前浏览器中的进度。

首击带有保护机制，不会因为第一次点击直接失败。若装备了对应道具，首击还可以扩大安全区。

## 记录系统

本地存档新增以下长期记录：

- `eliteOpened`
- `eliteDoomTriggered`
- `bestRewardByDifficulty`
- `bestTimeByDifficulty`

结算时如果刷新了当前难度的最高金币或最快时间，会在结果面板中显示 `New Record`。
