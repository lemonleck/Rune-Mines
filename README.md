# 尖塔扫雷

[<kbd>中文</kbd>](./README.md) [<kbd>English</kbd>](./README_EN.md)

带有成长、商店、出战配置与精英风险收益机制的网页版扫雷小游戏。玩家在不同规模的矿区中排雷，赚取金币和经验，逐步打造自己的配置，并在更高难度中挑战更高价值的赏金局。

## 本次更新

这次围绕“沉浸反馈组”新增了 3 个提升点：

1. 新增全局音效系统与 `SFX` 开关。
2. 新增强化的局内反馈层，包括连锁揭示提示、精英触发浮层和更明显的终局冲击反馈。
3. 新增结果战报摘要，结算面板会展示精英触发、最终赏金倍率与记录状态。

## 游戏特色

- 经典扫雷操作：左键翻开格子，右键插旗。
- 四档难度：简单、进阶、困难、终极，拥有不同棋盘规模、地雷数量、目标时间和奖励权重。
- 成长系统：胜利获得金币和经验，升级后提高收益倍率。
- 商店系统：可购买永久道具，并在出战配置中自由搭配。
- 成就与每日任务：提供中长期目标与稳定金币来源。
- 精英格风险收益：赌对了会放大奖励，赌错了可能让棋盘更危险。
- 沉浸反馈增强：局内有音效、浮层提示、棋盘冲击反馈和更完整的结算收尾。
- 本地存档：等级、金币、道具、设置和最佳记录等会保存在浏览器 `localStorage`。

## 精英格说明

每局会根据难度生成固定数量的精英格：

- `easy`：1 个
- `normal`：2 个
- `hard`：3 个
- `ultimate`：4 个

精英格类型：

- `Vault`
  - 触发后本局金币赏金 `x1.12`
  - 可多次叠加
- `Scout`
  - 自动展开周围最多 3 个安全未开格
  - 若周围没有合适目标，则改为揭示 1 个全局安全格
- `Doom`
  - 触发后本局金币赏金 `x1.20`
  - 同时会向棋盘中补入 1 颗新的隐藏地雷
  - 若没有合法位置补雷，则只保留赏金增益

## 音效与反馈

- 棋盘状态区新增 `SFX` 开关，默认开启，刷新后会保留当前静音状态。
- 使用原生 `Web Audio API` 生成轻量提示音，不依赖外部音频资源。
- 普通开格、连锁空白区、插旗、精英格触发、胜利与失败都拥有不同反馈。
- 精英事件除了消息文本外，还会额外显示反馈条和棋盘浮层提示。

## 如何运行

这是一个纯前端项目，不需要构建步骤。

1. 进入项目目录。
2. 用浏览器打开 `index.html`。
3. 开始游戏。

也可以使用任意静态文件服务器，例如 VS Code Live Server。

## 玩法说明

- 左键：翻开格子。
- 右键：插旗或取消插旗。
- 新一局：按当前难度重新开始。
- 升级：消耗金币提升角色等级。
- 购买道具：永久解锁新能力。
- 出战配置：控制本局生效的主动与被动道具。
- 重置存档：清空当前浏览器中的进度。

首击带有保护机制，不会因为第一次点击直接失败。若装备了对应道具，首击还可以扩大安全区。

## 结果战报

结算面板会显示：

- 本局翻开的精英格数量
- `Vault / Scout / Doom` 各自触发次数
- 最终赏金倍率
- 是否刷新金币记录或最快时间记录
- 一句根据风险与结果生成的总结文案

## 记录系统

本地存档会持续记录：

- `eliteOpened`
- `eliteDoomTriggered`
- `bestRewardByDifficulty`
- `bestTimeByDifficulty`
- `settings.soundEnabled`

若刷新了当前难度的最高金币或最快时间，结果面板会显示 `New Record`。
